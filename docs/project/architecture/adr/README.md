# Project architecture decisions

This registry contains only decisions about the software developed under
`data/`. Decisions about Habenae itself live under `docs/habenae/adr/`.

ADRs are named `NNNN-short-title.md`. An accepted decision is never rewritten;
a new ADR supersedes it and references its number.

Copy the [ADR template](../../../templates/adr.md) to create a decision.
