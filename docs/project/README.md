# Software project documentation

The project's purpose and essential external links are defined in
[PROJECT.md](../../PROJECT.md).

This domain describes the software whose source code is mounted under `product/`.
It is versioned in Habenae so that it remains available to the orchestrator,
while the code repository remains free of agentic files.

- [Project documentation](documentation/README.md): behavior, concepts,
  interfaces, operations, and technical guides;
- [Project architecture](architecture/README.md): components, boundaries, flows,
  quality attributes, and architecture decisions.

Pages must reference the corresponding specifications and stories. Code
references identify the relevant repository, branch, and SHA.
