# Habenae architecture decisions

This registry contains only decisions about the orchestrator, its organization,
and its operation. Decisions about the software being developed live under
`docs/project/architecture/adr/`.

ADRs are named `NNNN-short-title.md`. An accepted decision is never rewritten;
a new ADR supersedes it and references its number.

Copy the [ADR template](../../templates/adr.md) to create a decision.
